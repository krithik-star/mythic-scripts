## 🚀 How to Upload to GitHub and Host on GitHub Pages

### 1. Initialize and Commit (Already Done Locally)
```bash
git init
git add .
git commit -m "Initial commit: Mythic AI website with YouTube channels and scripts"
```

### 2. Connect to Your GitHub Repository
1. Go to [GitHub](https://github.com/new) and create a repository (e.g., `mythology-ai-studio`).
2. Run these commands in your terminal:
```bash
git remote add origin https://github.com/YOUR_USERNAME/mythology-ai-studio.git
git branch -M main
git push -u origin main
```

### 3. Turn on Free GitHub Pages
1. Go to your GitHub repository > **Settings** > **Pages** (left sidebar).
2. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. In about 1 minute, your site will be live at:
   `https://YOUR_USERNAME.github.io/mythology-ai-studio/`

## ⚙️ Customizing Channel Links in the Browser
Click the ⚙️ gear icon next to either Subscribe button on the website to set your custom YouTube channel handle or URL. The URL automatically appends `?sub_confirmation=1` so viewers get the instant subscribe popup!
